# 教训沉淀 — 从实施过程发现的设计缺口

> 本文件记录从真实项目实施（示例REQ-B 示例分析平台 V2 开发）中发现的设计文档缺口与修复方案，供后续需求设计时参考。

---

## 教训 1：数据时间戳缺失

**问题**：原型和数据 API 返回数据时没有显示数据的截止时间（如"数据更新于 12:00"）。用户不知道数据的时效性，容易做出错误判断。

**实际后果**：开发中需要额外加"数据更新时间"字段、修改 API 返回结构、前端展示。

**修复方案**：PRD 功能说明模板增加"数据时间戳"必填子节。
**对应契约**：Guardrail #10

---

## 教训 2：数据降级链路不完整，离线场景未定义

**问题**：设计文档写了"主数据源 不可用时降级到备用数据源"，但没写：
- 备用数据源也不可用怎么办？
- 完全无网络时用内置演示数据还是展示"暂无数据"？
- 每级降级对用户的影响是什么？

**实际后果**：开发中需要补 第三方适配器 适配器 + 复合数据源 复合数据源 + 离线新闻样本库。

**修复方案**：PRD 功能说明模板增加"数据降级链路"必填子节，明确 3 级降级 + 每级用户影响。
**对应契约**：Guardrail #11，reviewer审核新增"离线降级检查"

---

## 教训 3：算法边界条件未定义

**问题**：计算引擎的定投每周偏移(day%5 → (day-1)%5)、统计模块 缺 max_return_value 字段、定投模块 缺 lump_sum_date_field 字段，都暴露了设计文档没有覆盖算法边界条件。

**实际后果**：多次修复 + 1 次"HIGH bug"修复。

**修复方案**：PRD 功能说明模板增加"算法边界"子节，覆盖零输入/单值输入/整除边界/索引越界/时序靠后数据不完整。
**对应契约**：Guardrail #12

---

## 教训 4：API 字段清单与原型展示字段不一致

**问题**：原型中设计了"状态角标"、"分组 Tab"、"搜索补全"等交互元素，但 PRD 中没有对应的功能说明和验收条件。开发时原型和 API 的字段对不上，需要反复对齐。

**实际后果**：1 次"原型对齐修复"commit，修改了 21 个文件。

**修复方案**：新增 Guardrail #13 "原型-实施对齐契约"。reviewer在原型产出后必须做"原型-PRD对齐检查"。
**对应契约**：Guardrail #13，reviewer SKILL.md 新增"原型与PRD对齐检查"

---

## 教训 5：批量调用性能未定义

**问题**：自选清单列表对每条记录串行拉取数据，页面加载极慢。设计文档没有定义"批量数据的拉取方式（并行/串行）"。

**实际后果**：开发中改为 asyncio.gather + asyncio.to_thread 并行拉取，修复为"HIGH bug"。

**修复方案**：TDL 新增"并行/串行策略"条目。reviewer新增"并发性能检查"。
**对应契约**：TDL-08，reviewer SKILL.md

---

## 教训 6：运行时版本兼容性未声明

**问题**：设计文档假设 Python 3.11，但部署环境是 Python 3.9。`X | None`、`list[X]` 等语法不兼容。

**实际后果**：全局修改所有 Python 文件，补充 `from __future__ import annotations` + typing 导入。

**修复方案**：TDL 新增"最低运行时版本（详细）"条目，明确注明版本兼容语法规则。
**对应契约**：TDL-09

---

## 教训 7：模块循环依赖未防护

**问题**：main.py 和 service 工厂函数之间产生循环导入。

**实际后果**：重构为 dependencies.py 统一注入。

**修复方案**：TDL 新增"循环依赖防护"条目，reviewer审核检查依赖图单向性。
**对应契约**：TDL-10

---

## 教训 8：数据持久化方案模糊

**问题**：本地缓存数据存 LocalStorage，但刷新后某些页面的自选清单、基金关注等数据丢失。设计文档对"什么数据刷新后保留，什么不保留"定义模糊。

**实际后果**：开发中需要在多处加 localStorage 持久化和恢复逻辑。

**修复方案**：PRD 功能说明模板加强"数据持久化"子节，明确刷新保留/清除条件。
**对应契约**：Guardrail #9（已有，但检查力度加强）

---

## 教训 9：新闻情感评分的数据来源未定义降级

**问题**：情感评分依赖正负面词库匹配，但 主数据源 新闻源不可用时无降级。离线新闻 URL 包含星号错误。

**实际后果**：改为 fallback 优先策略：先用内置新闻样本，主数据源 实时新闻作为备选。

**修复方案**：PRD 功能说明模板的"数据降级链路"子节强调新闻/搜索等非核心功能的降级策略。
**对应契约**：Guardrail #11
