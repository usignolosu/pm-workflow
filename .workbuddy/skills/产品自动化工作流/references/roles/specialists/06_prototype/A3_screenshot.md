## 角色 A3：截图与标注索引（原型评审门前置）

### 触发条件
原型 HTML 产出完成后执行。在原型评审门等待 PM 审查之前完成。

### 输入
- prototype/ 目录（角色 A2 产出）
- final_prd.md

### 输出
两个：
1. `deliverables/REQ-XXX/01_drafted/screenshots/` 目录
2. `deliverables/REQ-XXX/01_drafted/annotation.md`

### screenshots/ 必须包含
- 每个核心页面一张 PNG 截图，分辨率 1280×900
- 截图上用红色圆圈标注编号 ① ② ③...，字体 14px 加粗
- 截图文件命名：`{序号}_{页面英文名}.png`（如 `01_fund_search.png`）

### 截图标注规则
- 编号顺序：页面内从上到下、从左到右编流水号
- 每个交互元素（按钮/输入框/表格行/弹窗/链接）都有独立编号
- 每个数据展示字段（涨跌幅/基金名称/K线/统计卡片）都有独立编号
- 状态性元素（加载态/空态/错误态）也需要编号

### annotation.md 必须包含
- 每个编号对应一个完整定义，格式如下：

```
### ① 搜索输入框
- **位置**：基金搜索页顶部
- **交互**：输入≥2字符后自动弹出候选下拉列表
- **数据源**：`GET /api/v1/funds/search?q={keyword}`
  - 出参：`{ items: [{code, name, type, index_name, nav, change}] }`
  - 降级：主源不可用 → 备用源 → 提示不可用
- **校验规则**：
  - 输入 < 2字符：不触发请求
  - 无匹配结果：显示"未找到相关基金"
- **样式状态**：
  - 空态：灰色 placeholder
  - 加载态：骨架屏
  - 正常态：下拉列表
  - 异常态：提示文字
- **字段清单**：
  | 字段 | 来源 | 格式 |
  |---|---|---|
  | 基金代码 | API.code | 6位数字 |
  | 涨跌幅 | API.change | +0.00% / -0.00% |
```

### 编号锁定规则
- 原型评审门通过后，annotation.md 中的所有编号**锁定**
- 实施阶段不增删改编号，研发用编号沟通，"修复①的搜索延迟"
- 如需修改，走"改标注"退回流程，回复 PROTOTYPING
