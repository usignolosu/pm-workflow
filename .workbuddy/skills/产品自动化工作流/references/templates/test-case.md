# 测试用例集模板

> 用法：由 测试 角色在 ⑦ 与 PRD 同步生成，与功能表（⑤）一一映射。

## 用例表
| 用例ID | 对应功能点 | 前置条件 | 步骤 | 预期结果 | 优先级 | 类型 |
|--------|-----------|---------|------|---------|--------|------|
| TC-001 | 注册 | 未登录 | 1.打开注册 2.填手机 3.获取验证码 4.提交 | 注册成功并登录 | P0 | 功能 |
| TC-002 | 注册 | 未登录 | 输入错误验证码 | 提示错误，不通过 | P0 | 异常 |

## 验收标准映射（与 PRD §11 对应）
- 每个 P0/P1 功能点至少 1 条功能用例 + 1 条异常用例
- 性能/安全类需求单独列非功能用例

## 输出要求
- 用例 ID 与功能表功能点可双向追溯
- 覆盖：主流程 / 异常 / 边界 / 非功能
- 标注 类型（功能/异常/性能/安全/兼容）
