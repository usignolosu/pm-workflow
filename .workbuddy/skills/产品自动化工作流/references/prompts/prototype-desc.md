# 生成原型描述（喂给原型工具）

基于以上 PRD，请提取核心页面清单和每个页面的布局描述、
关键组件、交互逻辑，整理成原型生成说明书。
每个页面包含：页面名称、核心元素、布局结构、交互跳转关系。

输出格式（JSON 友好，便于 gen_prototype.py 消费）：
```json
{
  "pages": [
    {
      "name": "登录页",
      "elements": ["手机号输入", "验证码按钮", "登录按钮"],
      "layout": "居中卡片，上方 logo，下方表单",
      "interactions": {"登录按钮": "校验→跳转首页", "验证码": "60s 倒计时"}
    }
  ]
}
```
